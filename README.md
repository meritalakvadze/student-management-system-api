# student-management-system-api

## Project Description

Student Management System API is a backend application built with Node.js, Express.js, and MongoDB. The system allows users to register and log in, manage student records, and upload or download files.

## Features

* User Registration and Login
* JWT Authentication
* Student CRUD Operations
* File Upload and Download
* MongoDB Integration
* Authorization Middleware

## Technologies Used

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT
* bcrypt
* Multer

## How to Run

```bash
npm install
npm start
```

Create a `.env` file:

```env
MONGO_URI=mongodb://localhost:27017/uni
SECRET_KEY=jwtSectretKey
PORT=3000
```
